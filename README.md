# 📚 Kitap Takip Kanban Panosu

Okumak istediğim, okuduğum ve bitirdiğim kitapları görsel olarak takip etmemi sağlayan, Kanban mantığıyla çalışan modern bir web uygulaması. Kitaplar **Okunacak**, **Okunuyor** ve **Bitti** sütunları arasında tek tıkla taşınabilir. Veriler tarayıcıda saklandığı için sayfa yenilense bile kaybolmaz.

## ✨ Özellikler

- Kitap adı ve yazar bilgisiyle yeni kitap ekleme
- Kitabı üç sütun arasında butonlarla taşıma
- Kitap silme
- Sütunlarda kitap sayacı
- LocalStorage ile kalıcı veri saklama
- Mobil uyumlu (responsive) tasarım

## 🛠️ Kullanılan Teknolojiler

- **React** – Bileşen tabanlı arayüz geliştirme
- **Vite** – Hızlı geliştirme ortamı ve derleme aracı
- **Tailwind CSS** – Utility-first stil çatısı
- **LocalStorage** – Tarayıcıda kalıcı veri saklama

## 🚀 Kurulum Adımları

```bash
# 1. Depoyu klonlayın
git clone https://github.com/KULLANICI_ADINIZ/kitap-kanban.git

# 2. Proje klasörüne girin
cd kitap-kanban

# 3. Bağımlılıkları yükleyin
npm install

# 4. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda `http://localhost:5173` adresini açın.

Üretim sürümü için: `npm run build`
